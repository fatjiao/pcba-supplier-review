# PCBA 初筛工作簿

完整审核的工作簿依次包含「原理图评审」「原理图Checklist」「原理图与BOM」「PCB爬电距离检查」。独立 PCB 距离检查只交付第四项。采用用户指定模板时，映射下述字段、来源定位和工程师复核信息。资料只覆盖部分范围时，在相关表注明已查范围和缺口。

## 来源、范围和版面

- 在工作簿记录项目、供应商提交批次、板号、修订、装配变体、审核日期、报告编号及来源路径。保留板号、版次和日期原文，注明读自标题栏、发布清单、BOM 页头或文件名。能获取时记录源文件 SHA-256。用批次及提交包内相对路径区分同名文件。
- 区分原始材料、可读副本和派生证据。远程 AD 取证记录工程位置、AD 版本、变体、导出范围、影响结果的设置及回传结果。发生阻塞时，按 [本机与远程 AD 的工作流程](rdp.md) 记录已执行步骤和未覆盖范围。仅有 PDF 或导出件时，注明实际可查的页、对象及限制。
- 用深色表头、浅色分组和可换行的明细显示。冻结表头及主要定位字段，明细可筛选。用底色辅助区分结论，同时保留结论文字。当前工程师填报列标浅黄色并留空。Checklist 历史列用独立底色。调节列宽、行高，使算式、料描和来源定位可完整阅读。

## 1. 原理图评审

按图面功能、供电及信号关系划分模块，列出模块范围和代表器件。每个图面位号一行，保留有证据的测试点、预留件和编译遮罩对象。

列序为「功能模块」「位号」「计算／复核状态」「原理图器件参数」「原理图封装」「器件用途」「计算条件与算式」「AI选型结论」「原因／备注」「原图定位／依据」「工程师审核结论」。「计算／复核状态」说明作了何种核验，器件判断以「AI选型结论」为准。

逐器件按实际用途核算。记录输入值、单位、算式、工况和结果，区分图纸、规格、项目要求、实测及假定。关联器件可共用模块算式，相关行仍应有本器件的结果或回查位置。已有可定位额定值时，给出与计算或实测值的比较。测试点记录所测网络和用途，NC/DNP 按实装范围解释。无需计算的对象以连接、功能或装配依据作判断。

「AI选型结论」仅用下列标签，算值和复核内容放在相邻的「原因／备注」。

| 标签 | 判定口径 |
| --- | --- |
| 合适 | 计算或图面证据支持图示用途和名义工况。普通去耦或旁路电容按用途、容值和耐压判断。普通串阻、上拉和低功耗跳线按实际电路核对。有明确介质、ESR、有效容值、脉冲或特殊工况要求时，再检查该要求。 |
| 不合适 | 已确认的工作条件与可追溯额定值、裕量或明确设计要求冲突。备注写出工况、限制和差异。 |
| 待确认 | 具体差异或关键缺参可能改变选择，如实际应力接近额定、接口电平可能越界、脚位或装配有歧义。写明影响和所需资料。共用的温升、时序或变体问题集中在最直接相关的器件，其他行可引用。 |
| 不适用 | 当前范围明确排除或用于测量的对象，如确认不装的 NC/DNP、启用编译遮罩中的器件和测试点。保留位号和图面依据。 |

## 2. 原理图Checklist

按 [Checklist 条款映射](checklist.md) 取用正式条款。列序为 `No.`、`标准`、`Description`、`HW`、`评审`、`Remarks`、`AI结论`、`AI备注`。保留原编号、强制或建议级别、原文、分组及来源版本、工作表或页码。有原项目判定、历史备注或例图时一并保留，并明确标为历史来源。本次结论写入相邻的 AI 列，依据当前工件和证据。

条款行的「AI结论」只允许 `NC`、`NG`、`OK`，用数据验证限制取值。

- **NC**。有证据表明本次板卡、变体或审核范围没有适用对象，或条款触发条件明确不成立。备注说明不适用依据。
- **OK**。条款适用且有现有证据支持符合。备注给出比较值、计算、来源位置或可回查的代表对象。复合条款覆盖各必要条件。
- **NG**。条款适用且出现偏差，或缺少通过初筛所需的关键依据。适用性尚不能排除时，记 NG 并注明缺口。备注区分已证实偏差、未达到建议或证据不足，写清影响范围和应补材料。证据不足的 NG 表示当前未达到初筛通过条件。

固定覆盖单位，通常为「原始条款 × 已声明板卡或变体」。需要按可枚举对象拆分时回链父条款，父条款仅汇总。页头、分组、历史示例和问题条数均不计入分母。`NC + NG + OK` 应等于正式审核单元数。百分比注明分子、分母和 NC 处理方式。缺少可采用的公司 Checklist 时，本页标注「资料预检，未形成公司合规结论」，列出缺件，覆盖率标为「不可计算」。

## 3. 原理图与BOM

逐位号覆盖原理图与 BOM 的并集。位号在多个板实例或变体中重用时，以范围及位号共同定位。多单元器件归并到原件位号。主料、替代料、互斥候选及冲突行保留各自来源和角色。无位号的装配件或外设单列，注明相关接口或总成。

列序为「位号」「原理图器件参数」「图示封装／外形」「原理图定位」「BOM器件描述」「BOM封装／原厂型号」「BOM原表位置」「料件角色／用量」「AI审核结论」「工程师审核结论」。原理图定位含页码、图框及位号。BOM 定位含工作表、物理行号及相关单元格。存在同版 PCB 证据时在审核结论中补对象、封装或焊盘位置。仅有 PDF 图面时注明无法据图确认的焊盘或装配信息。

- 读取正式 BOM 工作表和适用变体，保留来源版本、日期字段含义、相关隐藏行或表、原始料描、位号组、用量、料号及前导零。记录展开后的位号，保留主替代料或同位号分行关系。单位、封装别名和格式归一化用于比较，保留两侧原值。比较额定参数时，识别独立规格字段，避免将料号片段当作数值。
- 「AI审核结论」根据可比字段和装配证据使用「图表差异」「BOM独有」「原理图独有」「规格待核」「装配预留」「无位号料件」「可比字段相符」「图示NC」「测试点」「编译遮罩」，并说明具体差异、相符字段或缺口。单侧独有项注明检索范围。NC/DNP、二选一及跨变体物料按实际范围解释。原行用量、PCB 焊位存在和 PDF 图示分别支持各自的观察。
- 校验有效物料行、唯一位号、位号展开次数、原行用量和两侧并集。核对用量口径是单板、拼板或总成。重复、数量不符、无位号、未匹配、版本或变体未对齐等行均应可追溯。注明条件未满足时影响的范围及所需复核证据。

## 4. PCB 爬电距离检查

按 [PCB 距离取证和判定](pcb-distance.md) 选定公司表分支，逐个检查绝缘边界和适用条件。保留量测项目、PCB 层及铜边端点、图档和加工槽来源、工作电压、安规限值 J、公司推荐值 K、CAD 距离或上下界、AI 结论和证据。工程师结论单列留空。电气间隙与爬电分行，实物加工异常和假设漏铣情景分别定位。已验证 J ≤ 距离 < K 的项目判黄色 OK。实物未测、适用条件未知或量测区间跨底线时，记录具体缺口。

## 复核与交付校验

交付时保留 AI 判断和证据，工程师审核列留空。复审可用条款、范围、稳定对象和检查点匹配前次问题，记录本次变化、确认依据与关闭结果。严重度按已提供的公司分级依据记录。

回读审核工作簿，确认表名、顺序和范围正确，字段未被截断，逐位号与逐条款覆盖完整，来源可回查，正式 Checklist 条款的结论仅为 `NC`、`NG` 或 `OK`，当前工程师审核列为空。抽查典型相符、差异、缺证据、预留和未匹配记录，确认筛选、冻结和长文字显示。本地 Excel 交付文件链接，飞书模式按 [飞书发布](feishu.md) 回读在线表格后交付链接。
